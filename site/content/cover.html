The book

Building a personal agent, from first principles.

A textbook for the technically minded on how to build an assistant that lives in a chat, holds its owner's accounts, acts without being asked, and asks before anything that cannot be undone. Every mechanism is explained from the idea down to the code that runs.

What kind of book this is. It describes a real, open-source system that one person uses every day and that is still being built. Every claim about what was run is graded by how it is known, and anything not yet run is marked as such. The grades are explained in How to read the evidence. Read that page first; it takes three minutes.

How to read it

The chapters are organised by idea, not by the order in which things were built. Each one states what you will be able to do, defines its terms before using them, shows the design and the reasons for it, walks through the code that runs, says what went wrong in practice, and ends with exercises. Chapters refer to each other by number, and can be read out of order once Part I is behind you.

To understand how agents work

Read Part I, then the chapters on the conversation, memory and the gate. That is the smallest complete picture.

To build one

Read straight through to the end of Part IV with the repository open. Do the exercises; several ask you to change the code.

To make one safe

Read Part III in full, then the chapters on evaluation and on a second reading in Part V.
