A personal AI agent you run yourself

An assistant you message, that asks before it acts.

Odysseus lives in a private chat on Telegram, and optionally WhatsApp. It searches, remembers, reminds, watches for what you are waiting for, reads your mail and calendar, works in your other apps and browses the web. You run it yourself, on a laptop or a small server, with your own keys.

How it stays safe

The model proposes. Code grants.

A language model can be talked into things by a web page or an email. So the model never performs an action. It asks for one, and ordinary code decides. That code cannot be argued with.

  • The question is written by code from the real inputs, so it cannot describe one thing while requesting another.
  • Only a button counts. Typing "yes" is a message, not an approval.
  • Two locks. The tool itself refuses to run without an approval for those exact inputs, used once.
  • Silence means no. No answer, "stop", or nobody in the chat: it is not done.
Allow

Reading. Search, your mail and calendar, an app's data. Changes to Odysseus's own memory and reminders, which are reported to you each time.

Ask

Anything that reaches someone or cannot be undone. Sending mail, inviting guests, sharing or deleting in an app, setting up something that recurs.

Refuse

Everything else. A tool nobody wrote a rule for does not run.

Where this does not hold. The browser hands a whole task to another company's agent, and nothing asks before a click inside it. A browser run signed in as you asks you first, showing the task; after that it works unasked. One setting removes even that question. Chapter 11 says exactly what that gives up.

Run it yourself

Your bot, your keys, your server.

There is no hosted Odysseus and no account to create with us. You bring a Telegram bot and two keys, and it answers only you.

Get the keys

A bot token from Telegram's BotFather, a key for the model and a key for search. Mail, apps, the browser and file reading each add one optional key.

Run it on your laptop

Four commands. It starts answering in your Telegram chat. This is the right way to try it before paying for anything.

Give it a home

Deploy to a small always-on server so reminders fire while you sleep. The guide covers one host step by step, including what went wrong for us.
